# Sakan
Egyptian property discovery for buyers and renters. The product should feel welcoming, useful and credible, with a memorable image-led opening and quiet search tools.

## Direction
Use the clarity of Compass search and listing metadata as a reference, with a distinctly Egyptian location vocabulary. Avoid fabricated testimonials, counters and agent claims. Present seeded listings as sample properties.

Palette: Nile #183F56, Ocean #24657A, Ink #18313D, Sky #EAF2F5, Canvas #FFFFFF, Slate #647782. Use blue sparingly for actions and selection. Photography provides most of the color.
Typography: locally bundled Geist Sans for clear navigation and generous, tightly tracked headings; no decorative headline emphasis. 64px desktop hero, 38px mobile, 36px section titles, 15px body.
Layout: 1240px centered shell, an immersive villa hero, inset white search panel, three-column image-forward property grid, four neighborhood tiles. Left-aligned content. Rounded imagery at 16px; controls at 8px. Mobile bottom navigation.
Motion: a single restrained GSAP hero entrance, one React Bits BlurText heading, Lenis only on fine pointer devices; filters remain immediate, maps preserve native gestures. Reduced motion is static.

Review: search and property cards necessarily repeat familiar conventions because familiarity serves the broad audience. Remove generic badges, invented social proof and gratuitous card reveals. Let the hero photography carry the identity.
